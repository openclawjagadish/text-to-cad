# Starcloud-4 Space Data Center CAD Prototype

This directory contains a source-controlled build123d concept CAD prototype inspired by the public Starcloud-4 orbital data-center concept.

## Design Interpretation

The model is a lightweight in-orbit modular data center assembly in millimeters:

- `solar_mesh_panel`: a very large, thin, dark rectangular panel with outer rails, cross-grid members, and diagonal lattice rods.
- `main_data_center_module`: a white foreground rectangular data-center bus mounted above the panel, with dark side and rear panels plus raised Starcloud-style marking plaques.
- `compute_module_stack`: six repeated white server/compute modules in a side stack, each with seams, dark backplanes, small corner fasteners, and Starcloud-style plaques.
- `docking_port`: a circular port ring, center plug, and alignment pins mounted on the compute stack.
- `tug_capsule`: a nearby capsule/tug with cylindrical body, aft rounding, dark nose/window, winglets, top docking panel, forward probe, and markings.
- `connector_booms`: small rods tying the main module, stack, and tug/dock pose back to the panel architecture.

The geometry is intentionally low-detail so it remains fast to regenerate while still exporting real BREP solids through build123d and OCP.

## Regeneration

From the repository root, use the CAD skill STEP launcher with the repo virtualenv:

```bash
.venv/bin/python skills/cad/scripts/step \
  examples/starcloud-4/starcloud4_prototype.py \
  -o examples/starcloud-4/exports/starcloud4_prototype_build123d.step \
  --stl starcloud4_prototype_build123d.stl
```

The `--stl` path is interpreted relative to the STEP output directory by the launcher, so the command above writes:

- `exports/starcloud4_prototype_build123d.step` - primary CAD artifact.
- `exports/starcloud4_prototype_build123d.stl` - secondary mesh artifact.
- `exports/.starcloud4_prototype_build123d.step.glb` - adjacent CAD Explorer sidecar generated by the launcher.

- `exports/starcloud4_prototype_build123d_preview.png` - shaded render preview from `skills/cad/scripts/render`.

The generator also has a small direct entry point:

```bash
.venv/bin/python examples/starcloud-4/starcloud4_prototype.py
```

The launcher path is preferred because it performs the repo's standard STEP export flow and can create sidecars from the same `gen_step()` source.

```bash
  --facts --planes --positioning
find examples/starcloud-4/exports -maxdepth 1 -type f -name '*starcloud4_prototype_build123d*' -print -exec ls -lh {} \;
```
